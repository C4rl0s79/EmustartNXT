# Pliki

- [API /v1: urządzenia, konta, zapisy i grafiki](api-v1.md) - API urządzeń EmuStart Server pod /v1: wymóg HTTPS, logowanie urządzenia (enroll, challenge, token), biblioteka i pliki gier, synchronizacja zapisów, grafiki użytkowników, blokada profilu, folder profili, emulatory i BIOS-y oraz kody błędów.
- [Gry GOG z archiwum serwera](gry-gog.md) - Gry GOG w Lumenie bez GOG Galaxy i bez CDN GOG: archiwum depotów GOG Managera indeksowane na serwerze EmuStart, instalacja chunkami prosto do folderu gry, finalizacja kroków skryptów (rejestr, biblioteki systemowe, Execute) z jednym oknem UAC, uruchamianie (także bez launchera), zapisy przez serwer i odinstalowanie.
- [Motywy trybu TV jako paczki z serwera](motywy-tv.md) - Motywy trybu TV Lumena jako paczki .zip wgrywane w panelu serwera EmuStart: zawartość i zasady sprawdzania (themes.py), API /v1/themes, synchronizacja silnika do LumenData/themes, protokół lumen-theme://, bezpieczne wstawianie layers.html i poziomy animacji.
- [Serie gier (IGDB)](serie-gier.md) - Serie gier w Lumenie: serwer EmuStart dopasowuje gry w IGDB (seria = kolekcja, grupa = franczyza, data oryginału), udostępnia wynik przez /v1/series, silnik pobiera go metodą series_sync, a Lumen układa gry jednej serii razem — z kluczem z platformą, kolejnością po dacie oryginału i ręcznymi poprawkami gracza.
