# Klucz TheGamesDB

**Co daje:** [TheGamesDB](https://thegamesdb.net) — dodatkowe źródło grafik (okładki, zrzuty, banery) w oknie
„Grafiki” gry. Klucz jest opcjonalny.

## Krok po kroku

1. Załóż konto na [forum TheGamesDB](https://forums.thegamesdb.net/) i zaloguj się.
2. Poproś o klucz API w dziale forum przeznaczonym na prośby o dostęp do API. Klucze przydzielają administratorzy
   serwisu — zwykle trwa to od kilku godzin do kilku dni.
3. Gdy dostaniesz klucz (wystarczy klucz **public**), w Lumenie: **Ustawienia → Zaawansowane → IGDB i TheGamesDB →
   Klucz TheGamesDB** → wklej → **Zapisz**.

Informacje o API: [api.thegamesdb.net](https://api.thegamesdb.net/).
