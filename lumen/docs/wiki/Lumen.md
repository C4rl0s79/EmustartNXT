# Lumen

**Lumen** to launcher gier dla Windows: gry **Steam**, **GOG**, **Xbox** i gry na emulowane platformy z serwera
**EmuStart** w jednej bibliotece, w dwóch układach — **pulpit** (mysz i klawiatura) i **tryb TV** (pad, kanapa,
projektor). Przełączanie: F10 albo View + Start na padzie.

## Tryb TV

- [Tryb TV — listy gier, strona gry, ustawienia i sterowanie](Lumen-tryb-TV)

## Klucze i konta (Ustawienia → Zaawansowane)

Wszystkie klucze są opcjonalne — Lumen działa bez nich, dają tylko więcej danych.

- [Klucze API — przegląd](Klucze-API)
- [Klucz Steam Web API](Klucz-Steam-Web-API) — lista wszystkich gier konta Steam
- [Klucz SteamGridDB](Klucz-SteamGridDB) — plakaty, tła i logotypy
- [Klucze IGDB (Twitch)](Klucze-IGDB) — dodatkowe grafiki, serie gier na serwerze
- [Klucz TheGamesDB](Klucz-TheGamesDB) — dodatkowe grafiki
- [Xbox — własna aplikacja Azure](Xbox-aplikacja-Azure) — tylko gdy domyślne logowanie nie działa
