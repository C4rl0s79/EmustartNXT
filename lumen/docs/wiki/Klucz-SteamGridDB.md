# Klucz SteamGridDB

**Co daje:** plakaty, tła, logotypy i ikony gier z [SteamGridDB](https://www.steamgriddb.com) — dla gier Steam, GOG,
skrótów i gier EmuStart. W **Biblioteka → Grafiki** można ustawić, czy SteamGridDB ma pierwszeństwo przed
oficjalnymi grafikami.

## Krok po kroku

1. Wejdź na [steamgriddb.com](https://www.steamgriddb.com) i zaloguj się (**Login** w prawym górnym rogu — np.
   kontem Steam).
2. Otwórz [Preferences → API](https://www.steamgriddb.com/profile/preferences/api).
3. Naciśnij **Generate API Key** i skopiuj klucz.
4. W Lumenie: **Ustawienia → Zaawansowane → SteamGridDB → Klucz SteamGridDB** → wklej → **Zapisz**.

Grafiki pojawiają się stopniowo, gdy przeglądasz bibliotekę; są zapisywane w pamięci podręcznej Lumena. Własny
wybór grafiki dla gry: strona gry → Opcje gry → **Grafiki**.
